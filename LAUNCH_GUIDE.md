# Launch Guide — Idongesit Willie Bassey Customer Success Portfolio

## Recommended setup
**GitHub = source of truth**  
**Netlify = main public hosting**  
**Lovable = optional future AI design/editor layer**  
**Custom .com = later**

## GitHub
1. Sign into your GitHub account.
2. Create a **public** repository called `customer-success-portfolio`.
3. Upload every file/folder from this portfolio folder into the repository root.
4. Commit to `main`.

If you prefer GitHub Pages as the public host, instead name the repository `YOUR-GITHUB-USERNAME.github.io`, then open:
**Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

## Netlify — recommended public host
1. Create/sign into Netlify.
2. Open **Projects → Add new project → Import an existing project**.
3. Select **GitHub**.
4. Authorize Netlify and select your portfolio repository.
5. This site is plain HTML/CSS/JS, so it needs no build command.
6. Publish.
7. Change the generated Netlify project/site name to a professional available name.

Temporary URL example:
`https://idongesit-willie-bassey.netlify.app`

Alternative: use Netlify drag-and-drop and drop the unzipped portfolio folder into Netlify Drop.

## Lovable
Lovable is optional. If you later want to rebuild/refine the site there:
1. Sign into Lovable.
2. Open **Settings → Connectors → GitHub**.
3. Connect GitHub and authorize the Lovable GitHub App.
4. Connect a Lovable project to GitHub.
5. Keep this current GitHub repository safe until you confirm the Lovable version is better.
